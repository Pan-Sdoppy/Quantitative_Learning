# A股个人量化交易框架（主板1天持仓动态卖出策略）

基于 **LightGBM + XGBoost + MLP 三模型集成** 的A股主板量化选股系统，面向个人投资者，适配 RTX 4070 Ti Super 16GB 显卡。核心优化目标为
**收益/时间比最大化**。

> **策略说明**：仅沪深主板股票，T日预测选股，T日尾盘（14:
> 50）全仓买入Top1（权重100/0/0），1天后动态卖出。T+1开盘高开≥1.5%则开盘价止盈，盘中最高价涨≥4.0%则按4.0%止盈价成交（不止损），否则收盘价卖出。优化目标=单位时间收益最大化。

> **GPU说明**：MLP使用PyTorch GPU加速（稳定）；LightGBM的GPU模式在部分Windows环境下会原生崩溃，默认使用CPU（此数据量CPU训练也很快，单周期约10秒）。

## 一、重要规则（必须遵守）

### 规则1：数据缓存与异常隔离

- **所有下载数据永久缓存**：每只股票存为独立parquet文件（`data/raw/{code}.parquet`），中途失败不影响已下载数据
- **元数据缓存**：`data/raw/_meta.json` 记录每只股票最新日期，启动时秒级判断是否需要更新，无需逐个读文件；元数据可从实际文件重建
- **股票列表缓存**：`data/raw/_stock_list.csv` 缓存7天（股票列表变化极慢），API失败时自动回退到过期缓存，30秒socket超时防挂起；
  **无论在线获取还是读本地缓存，返回前都强制执行“剔ST/退市 + 仅主板(60/00)”过滤，杜绝含ST的脏缓存混入下载与训练**
  （当前干净主板非ST约3051只）
- **因子数据缓存**：`data/processed/factor_data.parquet` 缓存计算结果，数据未变则直接复用
- **单股失败不影响全局 + 自动恢复**
  ：每只独立下载，失败递增重试3次（1s/2s退避），15秒socket超时快速判卡死；连续3只失败判定连接老化/限流，自动logout/login重连；第一轮结束后对失败股票自动补下载2轮；网络失败(
  None)与“节假日无数据”(空表)严格区分，绝不把失败静默当skip
- **单线程下载**：akshare内嵌V8引擎(py_mini_racer)不支持多线程初始化，多线程会原生崩溃，故使用单线程；配合元数据缓存，已有数据秒级skip，仅新数据需下载
- **智能skip窗口**：工作日用1天窗口（确保周一能获取周五之后的新数据），周末用3天窗口（避免周末重复空检查）；工作日空下载不更新元数据（盘前运行返回空，盘后可重试）

### 规则2：每次运行必重训 + 训练过程断点保护

- **每次运行train.py都从头训练所有模型**，不因为之前训练过就跳过。用户运行训练的目的就是重训
- **训练过程中断点保存**：每个模型训练完成后立即保存并更新checkpoint，训练过程中崩溃后重启可从已完成的模型继续（不会丢失已训练好的模型）
- **逐模式隔离**：动态卖出模型训练，报错不影响其他环节，失败记录日志后继续
- **因子缓存复用**：数据日期未变则跳过因子重算，直接加载缓存
- **异常捕获**：训练、回测、预测各环节均有try/except，报错记录日志后继续，不会全盘崩溃

### 规则3：模型覆盖保存，无垃圾文件

- **一次训练产出两套模型**：回测模型保存到 `models/latest/backtest/`，预测模型保存到 `models/latest/predict/`，每次训练覆盖旧模型
- **文件命名固定**
  ：每套模型包含 `lgb_1d_close.txt`、`xgb_1d_close.json`、`mlp_1d_close.pt`、`ensemble_1d_close.json`、`_checkpoint.json`
- **回测结果覆盖**：`results/latest/` 下固定文件名，每次回测覆盖
- **根目录只有5个文件**：`train.py`、`backtest.py`、`predict.py`、`requirements.txt`、`README.md`，其余均为文件夹

## 二、模型架构

### 2.1 集成模型（LightGBM 35% + XGBoost 35% + MLP 30%）

| 组件   | 模型                         | 加速          | 说明                                         |
|------|----------------------------|-------------|--------------------------------------------|
| 主模型1 | LightGBM                   | CPU         | GBDT梯度提升，处理44个因子非线性关系                      |
| 主模型2 | XGBoost                    | CPU/GPU     | 第二棵GBDT树，与LightGBM形成多样性互补，降低过拟合            |
| 辅模型  | MLP (4层: 512→256→128→64→1) | PyTorch GPU | 捕捉深层非线性模式，BatchNorm+Dropout，4070Ti Super加速 |
| 融合   | 加权平均                       | -           | LightGBM×0.35 + XGBoost×0.35 + MLP×0.30    |

### 2.2 持仓周期：1天持仓，动态卖出

只做 **1天持仓**，训练动态卖出模型：

| 卖出方式 | 标识         | 买入      | 卖出                                                   | 止损                               |
|------|------------|---------|------------------------------------------------------|----------------------------------|
| 动态卖出 | `1d_close` | T日尾盘收盘价 | 动态：T+1高开≥1.5%开盘价止盈，盘中最高价≥4.0%按4.0%止盈价成交，否则收盘价卖出（不止损） | 开盘止盈1.5%/盘中止盈4.0%（经169组参数网格搜索最优） |

> **优化目标 = 单位时间收益最大化**：1天持仓，标签为「T+1卖出价/T日收盘价 - 1」，即单日收益率。
>
> - 动态卖出（1d_close）：T+1开盘高开≥1.5%则开盘价止盈锁定收益，盘中最高价≥4.0%则按4.0%止盈价成交，否则收盘价卖出（不设止损，经网格验证不止损收益最高，止损会被洗盘甩出）
>
> **预测排序**：预测结果按动态卖出(1d_close)置信度降序排序。

### 2.3 因子体系（44个因子）

- **动量因子**：1/3/5/10/20/60日收益率、对数收益率
- **均线因子**：MA5/10/20/60、价格/均线比、均线交叉比
- **MACD**：DIF、DEA、柱状图
- **RSI**：6/12/24日相对强弱
- **布林带**：上轨/中轨/下轨、%B、带宽
- **KDJ**：K/D/J值
- **成交量因子**：5/10日均量、量比、成交额比
- **波动率因子**：5/10/20日年化波动率
- **振幅与位置**：日内振幅、5/20日振幅、收盘位置、高低比
- **换手率因子**：5日均换手、换手比
- **跳空因子**：开盘跳空比
- **趋势强度**：20日趋势位置
- **横截面排名因子**：ret_5d、ret_20d、vol_ratio_5、turnover_ratio、rsi_12 的当日排名百分位（比绝对值更稳定）
- **资金流代理因子**
  （5个，经A/B验证大幅正向）：mf_net_proxy（主力净流入代理）、mf_intraday（日内资金流）、vol_price_div（量价背离）、obv_ma5_ratio（OBV偏离）、buying_strength（买入强度）
- **因子去冗余**：计算因子间相关矩阵，自动剔除相关系数>0.95的冗余因子（从54个精简到44个）

所有因子按日做 **横截面Z-score标准化** + 极端值截断（±5σ）。

> **市场状态特征**（沪深300收益率、趋势、波动率）不进入模型训练（每天所有股票相同，对横截面选股无帮助），仅用于回测时的市场择时判断。

### 2.4 置信度计算

置信度 = 预测收益率在全市场横截面的 **排名百分位**，取值 [0, 1]，保留 **4位小数**。

- 1.0000 = 全市场预测收益最高
- 0.5000 = 市场中位数水平
- 0.0000 = 全市场预测收益最低

## 三、数据处理规则

### 3.1 股票池过滤（仅主板）

| 过滤类型 | 规则                                                         |
|------|------------------------------------------------------------|
| ST股票 | 名称含 "ST" / "*ST" / "退" 自动剔除（在线列表与缓存读入均强制过滤，只保留当前非ST主板票）    |
| 退市股票 | 不在当前上市列表中，自动剔除                                             |
| 次新股  | 上市交易日不足60天剔除                                               |
| 停牌日  | 当日成交量为0的交易日剔除                                              |
| 价格异常 | 收盘价≤0或≥10000剔除                                             |
| 市场范围 | **仅沪深主板**：60开头(沪市主板)、00开头(深市主板)，剔除创业板(30)、科创板(68)、北交所(8/4) |

### 3.2 增量下载

- 首次运行：从 **2016年1月1日** 下载全市场日线数据（前复权）
- 后续运行：自动检测本地最新日期，仅下载增量部分
- **数据源**：历史日线用 **baostock**（免费、稳定、快速，不依赖V8引擎，平均0.5秒/只）；盘中实时行情用 akshare
  新浪接口（`stock_zh_a_spot`，稳定可用，约14秒获取全市场）
- baostock 登录后全局复用、下载完成登出；长连接连续大量请求后可能老化/被限流，连续3只失败自动重连恢复
- 单只股票失败递增重试3次；第一轮跑完后对失败股票自动补下载2轮（重连重试），仍失败的在结尾汇总；网络失败不会被误判为“无新数据”而静默跳过
- 全程 **tqdm进度条** 显示下载进度
- **预期最新交易日判断**：周一到周五15:00后为当天，15:00前为上一个工作日，周末为上周五，避免周末 skip 逻辑导致周五数据被跳过

|------|--------------|---------------------------------------------------------|
| 数据起始 | 2016-01-01   | 训练和回测数据起点                                               |
| 股票池  | 仅沪深主板        | 3000+只，剔除ST/退市/次新/停牌                                    |
| 每次持仓 | 1只股票（只买Top1） | 全仓：Top1 100% / Top2 0% / Top3 0%（经12种权重组合回测，全仓Top1收益最高） |
| 持仓周期 | 1天           | T日预测→T日尾盘买入→T+1动态卖出（开盘1.5%止盈+盘中4.0%止盈，不止损）              |

| 选股方式 | 预测收益Top3     | 按模型预测收益率排序                                              |
| 开盘止盈 | 1.5%         | T+1开盘高开≥1.5%则开盘价卖出（169组网格搜索最优）                          |
| 开盘止损 | 无            | 不设开盘止损（回测验证：止损会被洗盘甩出，不止损收益最高）                           |

| 盘中止盈 | 4.0%         | T+1盘中最高价涨≥4.0%按买入价×1.04止盈（169组网格搜索最优阈值）                 |
| 市场择时 | 极端熊市空仓       | 沪深300低于20日均线5%以上时空仓（仅极端熊市），其余正常持仓Top3                   |
| 训练模式 | 固定日期分割       | 回测模型训练到2023-12-31，回测从2024-01-01开始；预测模型100%全量数据训练        |
| 盘中预测 | 自动判断         | predict.py在交易日9:30-15:00自动更新实时数据，其余时间用存量数据              |
| 标签   | 1日收益率        | T+1卖出价/T日收盘价-1，单位时间收益最大化                                |
| 回测区间 | 默认验证集        | 从训练结束日之后开始（避免在训练数据上回测导致虚高）                              |

## 六、使用方法

### 6.1 训练模型（首次必跑）

```bash
# 用本地存量数据训练（回测模型+预测模型）
python train.py

# 先增量下载截止当前最新交易日的数据，再训练两套模型
python train.py --update

# 只训练预测模型，跳过回测模型（回测模型固定2016~2023，数据不变无需每次重训）
python train.py --skip-backtest

# 增量更新数据后只训练预测模型
python train.py --update --skip-backtest
```

> 数据更新由 `--update` 参数手动控制。不加参数时直接用本地数据训练，加 `--update` 时先增量下载最新交易日数据再训练。
>
> `--skip-backtest` 跳过回测模型训练，直接从已有回测模型加载最佳迭代次数来训练预测模型。回测模型固定训练到
> 2023-12-31，历史数据不变时无需重训，可大幅缩短日常更新时间。
>
> **不加 `--skip-backtest` 时，每次运行train.py都从头训练所有模型**，不跳过已训练模型。
>
> **数据完整性校验**：`--update` 增量下载后，若失败股票数 > 5
> 只，程序直接终止训练并打印原因，不进入后续因子计算和模型训练。需重新运行 `--update` 补齐失败股票后再训练，防止脏数据污染模型。

> **一次训练，两套模型**（自动产出，各自目录，每次覆盖）：
>
> | 模型 | 保存路径 | 训练数据 | 回测/验证集 | 用途 |
> |------|---------|---------|------------|------|
> | 回测模型 | `models/latest/backtest/` | 2016~2023-12-31 | 2024-01-01~最新 | `backtest.py` 自动加载，完整年度回测用于策略评估，同时确定最佳迭代次数 |
> | 预测模型 | `models/latest/predict/` | 2016~最新（100%全量） | 无（迭代次数从回测模型继承） | `predict.py` 自动加载，全量数据训练用于实盘选股 |
>
> 无需手动切换，回测和预测自动选择各自的模型。每次训练覆盖旧模型，不产生垃圾文件。

训练流程：数据增量更新 → 加载数据 → 计算因子 → 创建标签(T日尾盘买/T+1动态卖出) → 训练回测模型(训练到2023-12-31) →
训练预测模型(100%全量) → 保存。

### 6.2 回测

```bash
# 基于训练文件的最新数据回测（无参数）
python backtest.py
```

回测自动从训练结束日的下一天（2024-01-01）开始，使用验证集数据，避免在训练数据上回测导致虚高。输出：回测指标汇总表 +
交易明细 + 净值曲线 + 年度收益明细，保存在 `results/latest/`。

### 6.3 预测（每日选股）

```bash
# 无参数，自动判断当前时间
python predict.py
```

> **自动数据更新逻辑**：
>
> | 当前时间 | 数据来源 | 说明 |
> |----------|----------|------|
> | 交易日 9:30-15:00 | 自动更新最新实时数据 | 每次运行都获取当前最新实时快照（如14:17运行→获取14:17最新价），不缓存 |
> | 非交易日 / 非交易时段 | 训练文件的最新存量数据 | 不更新，直接用本地数据预测 |
>
> 预测时会打印本次预测基于的数据时间范围（如"本次预测基于实时数据: 2016-01-01 ~ 2026-08-21 14:15"）。
>
> 输出列包含：排名、股票代码、股票名称、所属板块（baostock行业分类，缓存到 `data/raw/_stock_industry.csv`）、收盘价、最新涨跌幅、状态。
>
> **结果保存**：所有预测结果写入同一个 Excel 文件 `results/latest/predict/predictions.xlsx`，每天一个 sheet（sheet
> 名=日期，如 `2026-09-21`）。同一天多次运行会先清空该 sheet 旧数据再写入新数据，不同日期自动新增 sheet。

输出格式：

```
排名 | 股票代码 | 股票名称 | 收盘价 | 最新涨跌幅 | 状态 | 动态卖出置信度
```

> **状态列**：最新涨跌幅≥9.9%标记为"涨停"（主板涨停10%，考虑四舍五入），否则标记为"可买入"，方便用户快速判断哪些股票尾盘能买到。
>
> **策略说明**：根据最新数据预测，当日尾盘（14:50）买入Top3，T+1动态卖出（高开2%止盈，低开2%开盘止损，否则尾盘卖，跌2%止损）。
>
> **盘中预测**：交易时间内自动获取当天实时行情（最新价），合并到历史数据重新计算因子后预测，用于当日尾盘买入决策。例如14:
> 17运行获取当天14:17的实时快照（盘中每次运行都重新获取最新数据，不缓存）。
>
> **预测不剔除涨停股**：输出全市场所有股票的置信度排名，包括涨停股，买不买得到由用户自行判断。

所有置信度保留 **4位小数**。

## 七、设计要点

1. **无未来函数**：因子计算严格使用当日及之前数据，标签使用未来数据但训练时正确隔离
2. **T日尾盘买入策略**：T日预测，T日尾盘（14:50）买入，1天后动态卖出
3. **单位时间收益最大化**：训练标签为1日收益率（T+1卖出价/T日收盘价-1），优化目标是收益/时间比
4. **仅主板股票**：3000+只沪深主板，剔除创业板/科创板/北交所，涨停统一10%
5. **每次运行必重训**：train.py每次运行都从头训练所有模型，不跳过；训练过程中每个模型完成后立即保存，崩溃后可从已完成模型继续
6. **GPU自适应**：自动检测LightGBM和PyTorch的GPU可用性，不可用时自动回退CPU；LightGBM GPU模式在Windows下原生崩溃，默认CPU
7. **异常隔离**：单只股票下载/因子计算失败不影响整体，记录日志后继续
8. **4070Ti Super适配**：MLP使用PyTorch GPU加速，BatchNorm+batch size(4096)
   ，显存占用约4-6GB；全量数据float32降精度，三模型顺序训练+及时释放中间数据，内存占用控制在16GB内
9. **回测真实性**：T日尾盘买/T+1动态卖出、扣除交易成本(0.35%/次)
   、默认在验证集回测、年度收益统计、回测剔除T日涨停股（尾盘封单买不进，保证回测真实）、开盘止盈(高开≥1.5%开盘卖)+盘中止盈(
   最高价≥4.0%止盈)、不设止损（回测验证不止损收益最高）、市场择时极端保护
10. **预测不剔除涨停股**：预测文件输出全市场所有股票的置信度排名，包括涨停股，买不买得到由用户自行判断；仅回测引擎剔除涨停股以保证真实性
11. **预测展示最新涨跌幅**：预测结果展示每只股票的最新涨跌幅，盘中运行用新浪实时行情的涨跌幅，非盘中用本地历史数据的当日涨跌幅
12. **内存优化**
    ：全流程float32降精度、因子计算分块处理+gc回收、丢弃冗余OHLCV列、创建标签不copy、三模型顺序训练（LightGBM→XGBoost→MLP）、每个模型训练完成后立即释放Dataset/DMatrix/GPU
    tensor中间数据、MLP原地标准化避免数组复制、XGBoost/LightGBM创建数据结构后删除原始numpy数组
13. **ret_1d_raw原始收益率**：横截面标准化会将ret_1d等因子转为z-score，单独保留ret_1d_raw原始收益率供参考
14. **最新交易日智能识别**：预测时自动选择股票数量≥1000的最新交易日，避免盘中数据不完整（只有少数股票有当日数据）导致预测失效
15. **收盘价与实际一致**：使用前复权(qfq)数据，最新交易日的qfq收盘价等于实际成交价，预测展示的收盘价可直接用于下单参考
16. **三模型集成**：LightGBM(35%) + XGBoost(35%) + MLP(30%)，两棵GBDT树形成多样性互补，MLP捕捉深层非线性，降低单一模型过拟合风险
18. **训练可复现（固定随机种子）**：LightGBM和XGBoost设置seed=42；MLP训练前固定random.seed(42)、np.random.seed(42)
    、torch.manual_seed(42)、cuda.manual_seed_all(42)
    、cudnn.deterministic=True，DataLoader使用固定generator种子。同样数据+同样参数，每次训练结果完全一致，避免MLP随机初始化导致回测结果跳变
17. **横截面排名因子**：关键动量/量能因子增加当日排名百分位特征，比绝对值更稳定，提升模型在不同市场环境下的泛化能力
19. **置信度加权持仓**：Top1 100% / Top2 0% / Top3
    0%，全仓买入置信度最高的股票，收益最大化。经12种仓位比例组合回测对比（2024-2026年），只买Top1(10:0:0)累计收益率最高(
    7.72亿%)，是5:3:2的57倍，追求收益时间比最大化
20. **动态止盈（不止损）**
    ：T+1开盘高开≥1.5%则开盘价止盈卖出（锁定高开收益避免尾盘回落）；盘中最高价≥4.0%则按4.0%止盈价卖出（169组网格搜索最优）；否则收盘价卖出。不设开盘止损和盘中止损（经多轮网格验证：-2%/-5%止损都会被洗盘甩出，不止损收益最高，因为小盘股波动大，止损容易在低点被洗出去后反弹）。高抛止盈+让亏损单自然回归，最大化收益/时间比
21. **市场择时极端保护**：沪深300低于20日均线5%以上空仓（仅极端熊市回避），其余时间正常持仓Top3，不在正常调整中干预
22. **市场状态特征不进模型**：沪深300相关特征每天所有股票相同，对横截面选股无帮助反而引入噪声，仅用于回测择时判断
23. **T日尾盘买入**：T日预测后当日尾盘（14:
    50）买入，1天后动态卖出。回测时用T日收盘数据模拟预测（历史日线回测不涉及盘中实时数据）；实盘预测时可在交易时间内自动获取当天实时行情更新因子后预测，14:
    50买入
24. **一次训练产出两套模型**：`python train.py`
    同时训练回测模型（训练到2023-12-31，回测从2024-01-01开始，保存到 `models/latest/backtest/`
    ）和预测模型（100%全量数据训练，迭代次数从回测模型继承，保存到 `models/latest/predict/`）。`backtest.py`
    自动加载回测模型，`predict.py` 自动加载预测模型，无需手动切换。每次训练覆盖旧模型，不产生垃圾文件
25. **盘中实时预测（自动判断，无参数）**：`predict.py` 自动判断当前时间，仅在交易日9:30-15:
    00交易时间内更新最新实时数据，每次运行都获取当前最新实时快照（如14:17运行→获取14:
    17最新价），不缓存。非交易日/非交易时段不更新，直接用训练文件的最新存量数据预测。预测时打印本次预测基于的数据时间范围
26. **回测剔除T日涨停股，预测不剔除**
    ：T日尾盘买入策略下，T日涨幅≥9.0%的股票尾盘封单买不进，回测时必须剔除以保证真实性。训练时保留涨停股（标签仍有效，模型可学习规律），预测时不剔除（输出全市场排名，买不买得到由用户判断）
27. **参数设计**：`train.py` 支持 `--update`（增量下载最新交易日数据再训练）和 `--skip-backtest`
    （跳过回测模型训练，只训练预测模型，回测模型固定2016~2023无需每次重训）；`backtest.py`
    无参数（基于训练文件最新数据回测）；`predict.py` 无参数（自动判断交易时间，盘中自动更新实时数据，其余时间用存量数据）
28. **预测输出涨停标记**：预测结果新增"状态"列，最新涨跌幅≥9.9%标记为"涨停"，否则标记为"可买入"
    ，方便用户快速识别尾盘封单买不进的股票。预测不剔除涨停股（输出全市场排名），仅回测引擎剔除涨停股以保证真实性
29. **当天日涨幅区间过滤（已写死启用）**：回测引擎支持`filter_today_day_ret`
    （上限：T日日涨幅ret_1d_raw超阈值剔除）和`filter_today_day_ret_min`（下限：T日日涨幅低于阈值剔除）两个参数。当前写死为**(
    无下限, +9.0%)区间**，即只买当天涨幅在9.0%以下的股票（不设下限）：
- **上限>9.0%剔除**（涨停股买不进）：9.0%以上的股票接近涨停，尾盘封单买不进
- **不设下限**（网格搜索最优）：169组网格搜索验证不设下限收益最高（6616万% vs -3%下限3915万%），暴跌股次日反弹概率高
- **其他已验证不推荐的过滤**：①只买阴线收盘（灾难性，累计收益-80%，胜率41%）；②剔除上影线异常（所有阈值累计收益均低于基准，夏普微升但得不偿失）；③方案一实体涨幅过滤（所有阈值总收益均低于基线）
- **已在backtest.py中写死启用**：常量`FILTER_TODAY_DAY_RET = 0.07`和`FILTER_TODAY_DAY_RET_MIN = -0.03`
  ，run_backtest调用时直接传入，无需命令行参数

30. **composite二次排序（已写死启用）**：模型粗筛Top10后，按7个因子综合排名重排选Top3：振幅小(权重2)、量比低(2)、跳空高(1)
    、换手率低(1)、成交额低(1)、5日位置高(1)、3日动量高(1)
    。经169组网格搜索验证：振幅2+量比2最优（10014万%，夏普15.29，胜率83.7%）。学习型reranker（MLP二次排序）经A/B测试为负向，已禁用，改用手工composite规则

## 八、注意事项

- 本项目仅供学习研究，不构成投资建议
- A股市场有风险，量化策略历史回测不代表未来收益
- 首次运行数据下载耗时较长（全市场约3000只主板股票），请耐心等待
- 建议在交易时段外运行训练，避免数据接口不稳定
- 模型需定期重新训练（建议每周一次）以适应市场变化
