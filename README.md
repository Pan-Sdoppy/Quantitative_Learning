# A股个人量化交易框架（主板1天持仓动态卖出策略）

基于 **LightGBM + XGBoost + MLP 三模型集成** 的A股主板量化选股系统，面向个人投资者，适配 RTX 4070 Ti Super 16GB 显卡。核心优化目标为**收益/时间比最大化**。

> **策略说明**：仅沪深主板股票，T日预测选股，T日尾盘（14:50）买入Top3，1天后动态卖出。T+1开盘高开≥2.5%则开盘价止盈，开盘低开超5%则开盘价止损，否则持有到尾盘，收盘价跌超5%按-5%止损，否则收盘价卖出。优化目标=单位时间收益最大化。

> **GPU说明**：MLP使用PyTorch GPU加速（稳定）；LightGBM的GPU模式在部分Windows环境下会原生崩溃，默认使用CPU（此数据量CPU训练也很快，单周期约10秒）。

## 一、重要规则（必须遵守）

### 规则1：数据缓存与异常隔离
- **所有下载数据永久缓存**：每只股票存为独立parquet文件（`data/raw/{code}.parquet`），中途失败不影响已下载数据
- **元数据缓存**：`data/raw/_meta.json` 记录每只股票最新日期，启动时秒级判断是否需要更新，无需逐个读文件；元数据可从实际文件重建
- **股票列表缓存**：`data/raw/_stock_list.csv` 缓存7天（股票列表变化极慢），API失败时自动回退到过期缓存，30秒socket超时防挂起
- **因子数据缓存**：`data/processed/factor_data.parquet` 缓存计算结果，数据未变则直接复用
- **单股失败不影响全局**：每只股票独立下载，失败自动重试2次，20秒超时强制跳过，记录日志后继续
- **单线程下载**：akshare内嵌V8引擎(py_mini_racer)不支持多线程初始化，多线程会原生崩溃，故使用单线程；配合元数据缓存，已有数据秒级skip，仅新数据需下载
- **智能skip窗口**：工作日用1天窗口（确保周一能获取周五之后的新数据），周末用3天窗口（避免周末重复空检查）；工作日空下载不更新元数据（盘前运行返回空，盘后可重试）

### 规则2：每次运行必重训 + 训练过程断点保护
- **每次运行train.py都从头训练所有模型**，不因为之前训练过就跳过。用户运行训练的目的就是重训
- **训练过程中断点保存**：每个模型训练完成后立即保存并更新checkpoint，训练过程中崩溃后重启可从已完成的模型继续（不会丢失已训练好的模型）
- **逐模式隔离**：动态卖出模型训练，报错不影响其他环节，失败记录日志后继续
- **因子缓存复用**：数据日期未变则跳过因子重算，直接加载缓存
- **异常捕获**：训练、回测、预测各环节均有try/except，报错记录日志后继续，不会全盘崩溃

### 规则3：模型覆盖保存，无垃圾文件
- **一次训练产出两套模型**：回测模型保存到 `models/latest/backtest/`，预测模型保存到 `models/latest/predict/`，每次训练覆盖旧模型
- **文件命名固定**：每套模型包含 `lgb_1d_close.txt`、`xgb_1d_close.json`、`mlp_1d_close.pt`、`ensemble_1d_close.json`、`_checkpoint.json`
- **回测结果覆盖**：`results/latest/` 下固定文件名，每次回测覆盖
- **根目录只有5个文件**：`train.py`、`backtest.py`、`predict.py`、`requirements.txt`、`README.md`，其余均为文件夹

## 二、模型架构

### 2.1 集成模型（LightGBM 35% + XGBoost 35% + MLP 30%）

| 组件 | 模型 | 加速 | 说明 |
|------|------|------|------|
| 主模型1 | LightGBM | CPU | GBDT梯度提升，处理54个因子非线性关系 |
| 主模型2 | XGBoost | CPU/GPU | 第二棵GBDT树，与LightGBM形成多样性互补，降低过拟合 |
| 辅模型 | MLP (4层: 512→256→128→64→1) | PyTorch GPU | 捕捉深层非线性模式，BatchNorm+Dropout，4070Ti Super加速 |
| 融合 | 加权平均 | - | LightGBM×0.35 + XGBoost×0.35 + MLP×0.30 |

### 2.2 持仓周期：1天持仓，动态卖出

只做 **1天持仓**，训练动态卖出模型：

| 卖出方式 | 标识 | 买入 | 卖出 | 止损 |
|---------|------|------|------|------|
| 动态卖出 | `1d_close` | T日尾盘收盘价 | 动态：T+1高开≥2.5%开盘价止盈，低开超5%开盘价止损，否则尾盘收盘价（跌超5%按-5%止损） | -5%止损（经参数优化最优阈值） |

> **优化目标 = 单位时间收益最大化**：1天持仓，标签为「T+1卖出价/T日收盘价 - 1」，即单日收益率。
>
> - 动态卖出（1d_close）：T+1开盘高开≥2.5%则开盘价止盈锁定收益，开盘低开超5%则开盘价止损（避免亏损扩大），否则持有到尾盘，收盘价跌超5%按-5%止损（经参数优化最优阈值，松止损避免频繁被扫止损后反弹）；兼顾止盈和止损
>
> **预测排序**：预测结果按动态卖出(1d_close)置信度降序排序。

### 2.3 因子体系（54个因子）

- **动量因子**：1/3/5/10/20/60日收益率、对数收益率
- **均线因子**：MA5/10/20/60、价格/均线比、均线交叉比
- **MACD**：DIF、DEA、柱状图
- **RSI**：6/12/24日相对强弱
- **布林带**：上轨/中轨/下轨、%B、带宽
- **KDJ**：K/D/J值
- **成交量因子**：5/10日均量、量比、成交额比
- **波动率因子**：5/10/20日年化波动率
- **振幅与位置**：日内振幅、5/20日振幅、收盘位置、高低比
- **换手率因子**：5日均换手、换手比
- **跳空因子**：开盘跳空比
- **趋势强度**：20日趋势位置
- **横截面排名因子**：ret_5d、ret_20d、vol_ratio_5、turnover_ratio、rsi_12 的当日排名百分位（比绝对值更稳定）

所有因子按日做 **横截面Z-score标准化** + 极端值截断（±5σ）。

> **市场状态特征**（沪深300收益率、趋势、波动率）不进入模型训练（每天所有股票相同，对横截面选股无帮助），仅用于回测时的市场择时判断。

### 2.4 置信度计算

置信度 = 预测收益率在全市场横截面的 **排名百分位**，取值 [0, 1]，保留 **4位小数**。
- 1.0000 = 全市场预测收益最高
- 0.5000 = 市场中位数水平
- 0.0000 = 全市场预测收益最低

## 三、数据处理规则

### 3.1 股票池过滤（仅主板）

| 过滤类型 | 规则 |
|----------|------|
| ST股票 | 名称含 "ST" / "*ST" 自动剔除 |
| 退市股票 | 不在当前上市列表中，自动剔除 |
| 次新股 | 上市交易日不足60天剔除 |
| 停牌日 | 当日成交量为0的交易日剔除 |
| 价格异常 | 收盘价≤0或≥10000剔除 |
| 市场范围 | **仅沪深主板**：60开头(沪市主板)、00开头(深市主板)，剔除创业板(30)、科创板(68)、北交所(8/4) |

### 3.2 增量下载

- 首次运行：从 **2016年1月1日** 下载全市场日线数据（前复权）
- 后续运行：自动检测本地最新日期，仅下载增量部分
- **数据源**：历史日线用 **baostock**（免费、稳定、快速，不依赖V8引擎，平均0.5秒/只）；盘中实时行情用 akshare 新浪接口（`stock_zh_a_spot`，稳定可用，约14秒获取全市场）
- baostock 单次登录全局复用，下载完成后登出
- 单只股票下载失败自动重试2次，不影响整体流程
- 全程 **tqdm进度条** 显示下载进度
- **预期最新交易日判断**：周一到周五15:00后为当天，15:00前为上一个工作日，周末为上周五，避免周末 skip 逻辑导致周五数据被跳过

## 四、回测规则

| 参数 | 默认值 | 说明 |
|------|--------|------|
| 数据起始 | 2016-01-01 | 训练和回测数据起点 |
| 股票池 | 仅沪深主板 | 3000+只，剔除ST/退市/次新/停牌 |
| 每次持仓 | 3只股票（只买Top1） | 置信度加权：Top1 100% / Top2 0% / Top3 0%，全仓买入置信度最高的股票，收益最大化 |
| 持仓周期 | 1天 | T日预测→T日尾盘买入→T+1动态卖出（高开2.5%止盈+低开5%开盘止损+尾盘跌5%止损） |
| 卖出方式 | 动态卖出 | T+1高开≥2.5%开盘价止盈，低开超5%开盘价止损，否则尾盘收盘价跌超5%按-5%止损，否则收盘价卖出 |
| 选股方式 | 预测收益Top3 | 按模型预测收益率排序 |
| 动态止盈 | 2.5% | T+1开盘高开≥2.5%则开盘价卖出（经参数优化最优阈值） |
| 开盘止损 | -5% | T+1开盘低开超5%则开盘价止损卖出（避免亏损继续扩大） |
| 尾盘止损 | -5% | T+1收盘价跌超5%按买入价×0.95止损（经参数优化最优阈值） |
| 市场择时 | 极端熊市空仓 | 沪深300低于20日均线5%以上时空仓（仅极端熊市），其余正常持仓Top3 |
| 训练模式 | 固定日期分割 | 回测模型训练到2023-12-31，回测从2024-01-01开始；预测模型100%全量数据训练 |
| 盘中预测 | 自动判断 | predict.py在交易日9:30-15:00自动更新实时数据，其余时间用存量数据 |
| 标签 | 1日收益率 | T+1卖出价/T日收盘价-1，单位时间收益最大化 |
| 回测区间 | 默认验证集 | 从训练结束日之后开始（避免在训练数据上回测导致虚高） |
| 交易成本 | 0.35%/次 | 佣金万2.5(买卖)+印花税千1(卖出)+滑点千1(买卖) |
| 涨停处理 | 回测时剔除 | T日尾盘买入，T日涨停股尾盘封单买不进，需剔除（训练时保留，预测时不剔除） |

### 回测指标

- 累计收益率、年化收益率
- 夏普比率（年化）
- 最大回撤
- 胜率（盈利交易占比）
- 盈亏比（平均盈利/平均亏损）
- 单次平均收益
- 交易次数
- **年度收益明细**（每年收益率、交易次数、胜率、单次均收）

## 六、使用方法

### 6.1 训练模型（首次必跑）

```bash
# 用本地存量数据训练
python train.py

# 先增量下载截止当前最新交易日的数据，再训练
python train.py --update
```

> 数据更新由 `--update` 参数手动控制。不加参数时直接用本地数据训练，加 `--update` 时先增量下载最新交易日数据再训练。
>
> **每次运行train.py都从头训练所有模型**，不跳过已训练模型。

> **一次训练，两套模型**（自动产出，各自目录，每次覆盖）：
>
> | 模型 | 保存路径 | 训练数据 | 回测/验证集 | 用途 |
> |------|---------|---------|------------|------|
> | 回测模型 | `models/latest/backtest/` | 2016~2023-12-31 | 2024-01-01~最新 | `backtest.py` 自动加载，完整年度回测用于策略评估，同时确定最佳迭代次数 |
> | 预测模型 | `models/latest/predict/` | 2016~最新（100%全量） | 无（迭代次数从回测模型继承） | `predict.py` 自动加载，全量数据训练用于实盘选股 |
>
> 无需手动切换，回测和预测自动选择各自的模型。每次训练覆盖旧模型，不产生垃圾文件。

训练流程：数据增量更新 → 加载数据 → 计算因子 → 创建标签(T日尾盘买/T+1动态卖出) → 训练回测模型(训练到2023-12-31) → 训练预测模型(100%全量) → 保存。

### 6.2 回测

```bash
# 基于训练文件的最新数据回测（无参数）
python backtest.py
```

回测自动从训练结束日的下一天（2024-01-01）开始，使用验证集数据，避免在训练数据上回测导致虚高。输出：回测指标汇总表 + 交易明细 + 净值曲线 + 年度收益明细，保存在 `results/latest/`。

### 6.3 预测（每日选股）

```bash
# 无参数，自动判断当前时间
python predict.py
```

> **自动数据更新逻辑**：
>
> | 当前时间 | 数据来源 | 说明 |
> |----------|----------|------|
> | 交易日 9:30-15:00 | 自动更新最新实时数据 | 以15分钟为间隔向下取整（如14:17运行→更新到14:15数据），距上次更新不足15分钟则用缓存 |
> | 非交易日 / 非交易时段 | 训练文件的最新存量数据 | 不更新，直接用本地数据预测 |
>
> 预测时会打印本次预测基于的数据时间范围（如"本次预测基于实时数据: 2016-01-01 ~ 2026-08-21 14:15"）。

输出格式：
```
股票代码 | 股票名称 | 收盘价 | 最新涨跌幅 | 状态 | 出货置信度 | 动态卖出置信度 | 动态卖出预测收益
```
> **状态列**：最新涨跌幅≥9.9%标记为"涨停"（主板涨停10%，考虑四舍五入），否则标记为"可买入"，方便用户快速判断哪些股票尾盘能买到。
>
> **出货置信度**：0-1之间，越高表示主力出货可能性越大。基于专业5维度综合判断体系（共20+细分信号）：
> - **位置判断(20%)**：相对位置、距60日高点、累计涨幅、均线多头排列、布林上轨
> - **成交量判断(25%)**：量比、换手率、天量、持续放量、量价背离
> - **K线形态判断(25%)**：长上影、射击之星、吊颈线、高位十字星、看跌吞没、黄昏之星、连续阴线、跳空低开
> - **技术指标判断(15%)**：RSI超买、KDJ死叉、MACD顶背离/死叉、布林收口
> - **资金行为判断(15%)**：尾盘跳水、冲高回落、收盘价vs均价、连续资金流出、放量收阴
>
> 建议出货置信度>0.5的股票谨慎买入，>0.7的股票避免买入。

> **策略说明**：根据最新数据预测，当日尾盘（14:50）买入Top3，T+1动态卖出（高开2.5%止盈，低开5%开盘止损，否则尾盘卖，跌5%止损）。
>
> **盘中预测**：交易时间内自动获取当天实时行情（最新价），合并到历史数据重新计算因子后预测，用于当日尾盘买入决策。例如14:17运行获取当天到14:15的数据。
>
> **预测不剔除涨停股**：输出全市场所有股票的置信度排名，包括涨停股，买不买得到由用户自行判断。

所有置信度保留 **4位小数**。

## 七、设计要点

1. **无未来函数**：因子计算严格使用当日及之前数据，标签使用未来数据但训练时正确隔离
2. **T日尾盘买入策略**：T日预测，T日尾盘（14:50）买入，1天后动态卖出
3. **单位时间收益最大化**：训练标签为1日收益率（T+1卖出价/T日收盘价-1），优化目标是收益/时间比
4. **仅主板股票**：3000+只沪深主板，剔除创业板/科创板/北交所，涨停统一10%
5. **每次运行必重训**：train.py每次运行都从头训练所有模型，不跳过；训练过程中每个模型完成后立即保存，崩溃后可从已完成模型继续
6. **GPU自适应**：自动检测LightGBM和PyTorch的GPU可用性，不可用时自动回退CPU；LightGBM GPU模式在Windows下原生崩溃，默认CPU
7. **异常隔离**：单只股票下载/因子计算失败不影响整体，记录日志后继续
8. **4070Ti Super适配**：MLP使用PyTorch GPU加速，BatchNorm+batch size(4096)，显存占用约4-6GB；全量数据float32降精度，三模型顺序训练+及时释放中间数据，内存占用控制在16GB内
9. **回测真实性**：T日尾盘买/T+1动态卖出、扣除交易成本(0.35%/次)、默认在验证集回测、年度收益统计、回测剔除T日涨停股（尾盘封单买不进，保证回测真实）、动态止盈(高开≥2.5%开盘卖)+开盘止损(低开超5%开盘卖)+尾盘止损-5%（收盘价跌超5%按买入价×0.95成交，模拟实际止损单）、市场择时极端保护
10. **预测不剔除涨停股**：预测文件输出全市场所有股票的置信度排名，包括涨停股，买不买得到由用户自行判断；仅回测引擎剔除涨停股以保证真实性
11. **预测展示最新涨跌幅**：预测结果展示每只股票的最新涨跌幅，盘中运行用新浪实时行情的涨跌幅，非盘中用本地历史数据的当日涨跌幅
12. **内存优化**：全流程float32降精度、因子计算分块处理+gc回收、丢弃冗余OHLCV列、创建标签不copy、三模型顺序训练（LightGBM→XGBoost→MLP）、每个模型训练完成后立即释放Dataset/DMatrix/GPU tensor中间数据、MLP原地标准化避免数组复制、XGBoost/LightGBM创建数据结构后删除原始numpy数组
13. **ret_1d_raw原始收益率**：横截面标准化会将ret_1d等因子转为z-score，单独保留ret_1d_raw原始收益率供参考
14. **最新交易日智能识别**：预测时自动选择股票数量≥1000的最新交易日，避免盘中数据不完整（只有少数股票有当日数据）导致预测失效
15. **收盘价与实际一致**：使用前复权(qfq)数据，最新交易日的qfq收盘价等于实际成交价，预测展示的收盘价可直接用于下单参考
16. **三模型集成**：LightGBM(35%) + XGBoost(35%) + MLP(30%)，两棵GBDT树形成多样性互补，MLP捕捉深层非线性，降低单一模型过拟合风险
17. **横截面排名因子**：关键动量/量能因子增加当日排名百分位特征，比绝对值更稳定，提升模型在不同市场环境下的泛化能力
18. **置信度加权持仓**：Top1 100% / Top2 0% / Top3 0%，全仓买入置信度最高的股票，收益最大化。经12种仓位比例组合回测对比（2024-2026年），只买Top1(10:0:0)累计收益率最高(7.72亿%)，是5:3:2的57倍，追求收益时间比最大化
19. **动态止盈+开盘止损+尾盘止损**：T+1开盘高开≥2.5%则开盘价止盈卖出（经参数优化2.5%为最优止盈阈值，锁定高开收益避免尾盘回落）；开盘低开超5%则开盘价止损卖出（避免亏损继续扩大，按实际开盘价成交）；未触发开盘止盈/止损则持有到尾盘，收盘价跌超5%按买入价×0.95止损卖出（经参数优化-5%为最优止损阈值，松止损避免频繁被扫止损后反弹，模拟实际止损单到价即成交）。经典"截断亏损让盈利奔跑+高抛止盈"策略，最大化收益/时间比
20. **市场择时极端保护**：沪深300低于20日均线5%以上空仓（仅极端熊市回避），其余时间正常持仓Top3，不在正常调整中干预
21. **市场状态特征不进模型**：沪深300相关特征每天所有股票相同，对横截面选股无帮助反而引入噪声，仅用于回测择时判断
22. **T日尾盘买入**：T日预测后当日尾盘（14:50）买入，1天后动态卖出。回测时用T日收盘数据模拟预测（历史日线回测不涉及盘中实时数据）；实盘预测时可在交易时间内自动获取当天实时行情更新因子后预测，14:50买入
23. **一次训练产出两套模型**：`python train.py` 同时训练回测模型（训练到2023-12-31，回测从2024-01-01开始，保存到 `models/latest/backtest/`）和预测模型（100%全量数据训练，迭代次数从回测模型继承，保存到 `models/latest/predict/`）。`backtest.py` 自动加载回测模型，`predict.py` 自动加载预测模型，无需手动切换。每次训练覆盖旧模型，不产生垃圾文件
24. **盘中实时预测（自动判断，无参数）**：`predict.py` 自动判断当前时间，仅在交易日9:30-15:00交易时间内更新最新实时数据，以15分钟为间隔向下取整（如14:17运行→更新到14:15数据），距上次更新不足15分钟则用缓存。非交易日/非交易时段不更新，直接用训练文件的最新存量数据预测。预测时打印本次预测基于的数据时间范围
25. **回测剔除T日涨停股，预测不剔除**：T日尾盘买入策略下，T日涨幅≥9.5%的股票尾盘封单买不进，回测时必须剔除以保证真实性。训练时保留涨停股（标签仍有效，模型可学习规律），预测时不剔除（输出全市场排名，买不买得到由用户判断）
26. **参数设计**：`train.py` 支持 `--update` 参数（有则增量下载最新交易日数据再训练，无则用本地存量数据训练）；`backtest.py` 无参数（基于训练文件最新数据回测）；`predict.py` 无参数（自动判断交易时间，盘中自动更新实时数据，其余时间用存量数据）
27. **预测输出涨停标记**：预测结果新增"状态"列，最新涨跌幅≥9.9%标记为"涨停"，否则标记为"可买入"，方便用户快速识别尾盘封单买不进的股票。预测不剔除涨停股（输出全市场排名），仅回测引擎剔除涨停股以保证真实性
28. **主力出货置信度（专业5维度体系）**：预测结果新增"出货置信度"列（0-1），基于专业5维度综合判断体系（20+细分信号）判断主力出货可能性：①位置判断(20%)：相对位置、距60日高点、累计涨幅、均线多头、布林上轨；②成交量判断(25%)：量比、换手率、天量、持续放量、量价背离；③K线形态判断(25%)：长上影、射击之星、吊颈线、高位十字星、看跌吞没、黄昏之星、连续阴线、跳空低开；④技术指标判断(15%)：RSI超买、KDJ死叉、MACD顶背离/死叉、布林收口；⑤资金行为判断(15%)：尾盘跳水、冲高回落、收盘价vs均价、连续资金流出、放量收阴。出货置信度>0.5谨慎买入，>0.7避免买入。注：目前基于日线数据，无分时图分钟级数据，如需分时出货波形识别可后续添加分钟级数据下载

## 八、注意事项

- 本项目仅供学习研究，不构成投资建议
- A股市场有风险，量化策略历史回测不代表未来收益
- 首次运行数据下载耗时较长（全市场约3000只主板股票），请耐心等待
- 建议在交易时段外运行训练，避免数据接口不稳定
- 模型需定期重新训练（建议每周一次）以适应市场变化
