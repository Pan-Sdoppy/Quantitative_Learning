# 双创量化模型（创业板 + 科创板，±20%）

创业板（`300` / `301`）+ 科创板（`688` / `689`）隔日 T+1 短线模型。代码框架、因子体系、标签结构、
二次排序流程与主板一致；选股、择时、卖出参数在双创样本上独立回测调优，当前生产口径为 **B16**。
模型层（Stacking / 时间衰减 / 树超参 / MLP 结构 / 新因子 / 标签改造 / 异质模型族 / 真置信度）探索已全部闭环触顶，
历史实验脚本与证据归档在 `results/archive/`、`results/deep_opt/`，生产代码不含这些探索分支。

## 二、股票池与涨跌幅口径

- **股票池**：正则 `^(300|301|688|689)`；剔除 ST / *ST / 退市；上市不足 60 个交易日的次新股不纳入。
- **不纳入**：沪深主板（`60` / `00`）、北交所（`8` / `4` / `920`）。
- **涨跌幅**：
  - 科创板开市起即 ±20%；创业板 2020-08-24 注册制改革后为 ±20%（回测期内全程 20%，训练样本回溯到 2016 年时按日期分界处理涨停阈值）。
- **涨停剔除**：尾盘封单买不进的涨停股当日不买；阈值按个股 `code + date` 逐行计算，科创板 19.5%、创业板 2020-08-24 前 9.5%。
- **T 日涨幅区间过滤**：日涨幅 ≥ 12% 剔除（追高）、≤ −6% 剔除（暴跌），区间外不买。
- **盘中异常跳变**：实时价 vs 前复权昨收 |涨幅| > 21% 判为复权串行污染，剔除该股当日行。
- **实时快照健壮性**：新浪 `stock_zh_a_spot` 多轮并集后总数低于 1900 判定分页截断/异常并拒绝出预测，达到 2050 即提前停抓。

## 三、生产链路与模型结构

### 3.1 三个生产入口

| 入口 | 职责 |
|---|---|
| `train.py` | 增量下载数据、计算因子、两阶段训练回测模型、守卫回测通过后训练预测模型 |
| `backtest.py` | 加载 `models/latest/backtest`，在样本外区间完整回测并保存交易/空仓/净值产物 |
| `predict.py` | 加载 `models/latest/predict`，盘中实时快照或最新本地数据，输出次日候选与兑现提示 |

### 3.2 集成模型

- 结构：**LightGBM 0.4 + XGBoost 0.4 + MLP 0.2**，输出单一融合 pred；分项预测可分别访问。
- 设备：LightGBM / XGBoost 固定 CPU；MLP 使用 PyTorch，检测到 CUDA 可用时上 GPU。
- **标签口径（训练用）**：T 日尾盘买、T+1 卖；标签默认开盘止盈 0.5%、盘中止盈 4.5%，小阈值让模型聚焦识别"次日是否有上攻动能"。
- **兑现口径（回测/预测用）**：B16 动态开盘止盈 1.2% / 2.5%，随后移动止盈（冲高 0.75% 激活、从高点回撤 0.25% 卖出），与标签阈值刻意不同。
- 置信度 = pred 横截面排名百分位，与 pred 排序单调等价、不携带独立信息；选股只用融合 pred，二次排序不使用置信度。

### 3.3 每日选股流程（回测与预测同口径）

1. 模型对当日候选全集打分，取 pred 粗筛 **Top8** 候选池。
2. 池内剔除 `mf_net_proxy` 横截面分位 > 0.65 的极端放量票（大涨且放量最极端 = 情绪顶 / 次日 A 杀）；过滤后为空则该因子跳过。
3. **composite 二次排序**（rank 累加打分，score 越小越靠前），取 Top3，全仓买 Top1。
4. 信号强度过滤：二次排序后 Top1 的 pred < 1.0%，当日空仓（弱信号胜率显著低）。
5. 大盘择时：沪深300 当日收阴（当日收益 < 0）则空仓；极端熊市强制择时已关闭。
6. 买入价 = T 日收盘价，持仓 1 天；卖出顺序：开盘高开达到动态止盈 → 开盘价卖；否则盘中冲高 ≥0.75% 激活移动止盈，从高点回撤 0.25% 即按回撤线卖出；未激活或收盘仍在回撤线上方 → T+1 收盘价卖；**不止损**。

### 3.4 composite 二次排序构成

**基础 5 因子**（权重 `[4, 2, 1, 0, 1]`，顺序：振幅小 / 5 日量比小 / 跳空高 / 5 日位置高 / 3 日动量强；5 日位置项权重为 0，已关闭）：

| 项 | 因子 | 方向 | 权重 |
|---|---|---|---:|
| 1 | `amplitude_1d` 当日振幅 | 小 → 靠前 | 4 |
| 2 | `vol_ratio_5` 5 日量比 | 小 → 靠前 | 2 |
| 3 | `gap_ratio` 跳空 | 高 → 靠前 | 1 |
| 4 | `close_position_5d` 5 日位置 | 高 → 靠前 | 0（关闭） |
| 5 | `ret_3d` 3 日动量 | 强 → 靠前 | 1 |

**K 线形态**：上影线短（权重 1.0）；光头阳加分 / 光头阴减分（权重 0.5）。

**规模 / 量能 / 资金流**：流通市值对数 `mv_log_yi` 小（1.0）、10 日量比 `vol_ratio_10` 小（1.0）、日内资金流 `mf_intraday` 低（0.5）。
`mv_log_yi` 仅用于二次排序，不进入模型特征。

### 3.5 B16 生产参数（`backtest.py` / `predict.py` 顶部常量与 `train.py` 守卫 `GUARD_BT_KW` 三处写死一致）

| 参数 | 取值 | 说明 |
|---|---|---|
| `TOP_N` | 3 | 二次排序后取 Top3，全仓 Top1 |
| 候选池 | Top8 | pred 粗筛数量 |
| 追高上限 | 12% | T 日涨幅 ≥ 12% 剔除 |
| 暴跌下限 | −6% | T 日跌幅 > 6% 剔除 |
| 大盘收阴空仓 | 启用 | 沪深300 当日收益 < 0 不买 |
| 极端熊市择时 | 关闭 | 阈值 −1.0 |
| `MIN_PRED` | 1.0% | 二次排序后 Top1 pred 低于此值当日空仓 |
| 开盘动态止盈 | pred < 1% → 1.2%；pred ≥ 1% → 2.5% | 弱信号小赚快跑、强信号给空间 |
| 移动止盈激活线 | 0.75% | T+1 盘中最高价较开盘冲高 ≥0.75% 激活移动止盈 |
| 移动止盈回撤 | 0.25% | 激活后从盘中最高点回撤 0.25% 即卖出 |
| 止损 | 不启用 | — |
| 交易成本 | 0.35%/次 | 佣金 + 印花税 + 滑点 |
| 池内因子过滤 | `mf_net_proxy` 分位 > 0.65 剔除 | 极端放量票 |
| composite 权重 | `[4, 2, 1, 0, 1]` | 见 3.4 |

## 四、训练切分（严格无泄露）

- 数据起点 2016-01-01；因子去冗余相关性矩阵只用 ≤ 2021-12-31 样本。
- **阶段 1（早停定轮数）**：训练集 ≤ 2020-12-31，验证集 2021 全年（至 2021-12-30），记录 LightGBM / XGBoost 最佳迭代轮数、MLP 最佳 epoch。
- **阶段 2（固定轮数 refit）**：训练集 ≤ 2021-12-30，用阶段 1 轮数固定轮数重训；候选模型先跑守卫回测（2022-01-04 起，严格样本外），**总收益不低于现有基线才覆盖正式回测模型**。
- **预测模型**：守卫通过后，100% 全量数据训练，轮数继承阶段 1。
- 回测起点 2022-01-04；回测期数据不参与早停、去冗余或模型选择。
- 当前回测模型 checkpoint：45 因子、训练截止 2021-12-30、回测起点 2022-01-04、去冗余截止 2021-12-31，固定轮数 LGB 335 / XGB 187 / MLP 24。

## 八、数据口径与防御规则

- **日线来源**：baostock 前复权（`adjustflag="2"`），字段 `date, open, high, low, close, volume, amount, turn`；`pct_chg = close.pct_change() * 100` 本地计算，`turn` 重命名为 `turnover`。
- **大盘指数**：沪深300 走 akshare `stock_zh_index_daily(symbol="sh000300")`。
- **全历史跳变校验**：非次新（前 60 行豁免）单日跳变 | > 22% 判为复权串行污染；增量衔接只取严格晚于本地末日的第一行比较，|跳变| > 22% 且非次新（本地不足 60 行豁免）转全量重拉。
- **加载时剔除**：停牌（volume = 0）、close ≤ 0 或 ≥ 10000、日收益率绝对值 > 50% 的极端异常行；次新股不足 60 行不纳入。
- **baostock 限制**：全局单例会话，禁止并发连接 / 多进程；单账号日请求 ≤ 5 万次，晚高峰易拥塞，白天或错峰执行；不要同时跑多个子项目下载。

## 九、改动纪律与注意事项

- **因子一致性**：训练 / 回测 / 预测三者因子列表完全一致，以训练时去冗余后的因子为准；回测、预测从模型 `meta.json` / `ensemble.json` 读取 `feature_names`。
- **新方案上线门槛**：任何参数、因子、规则改动，必须先在完全相同样本集（同股票池 / 同时段 / 同过滤条件）完整回测，并排对比开仓天数、平均收益、胜率（夏普 / 回撤 / 盈亏比为辅），收益与胜率均不低于 B16 基线才允许改生产代码；改完同步 README、注释并重跑完整回测。区分"原始 pred 排序"与"二次排序后"两个口径，不得混为一谈。
- **日志口径**：空仓日逐条日期 + 原因走 DEBUG（默认不打印），控制台 INFO 仅按原因分组计数；月度汇总包含 0 交易空仓月。临时需要逐日交易明细时单独开启 DEBUG 级别查看。
- **预测输出**：结果直接在对话中展示，不内置企业微信推送；预测表格"所属板块"列固定放在最右边；量化结果只输出 `.xlsx`。
- **快照阈值校准**：`SPOT_MIN_BOARD / SPOT_TARGET_BOARD` 按 2026-10 新浪实测单轮快照（约 2027 只，含 ST）设定；若上市数量明显变化需重新校准，避免漏票。
- **历史归档**：`results/archive/` 内为回测层历史网格、稳健性、守卫与一次性数据修复脚本；`results/deep_opt/` 为模型层 L0/L1/L2 探索证据。归档脚本的相对 import 在子目录已失效，作为历史快照留存、不复跑。
